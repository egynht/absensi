# PETUNJUK

## Instalasi

1. **Clone Repositori**  
   Gunakan perintah berikut untuk meng-clone repositori:  
   ```bash  
   git clone https://github.com/egynht/absensi.git  
   ```  

2. **Instal Dependensi**  
   Setelah clone selesai, navigasikan ke direktori repositori dan instal dependensi yang diperlukan:  
   ```bash  
   cd absensi  
   npm install  
   ```  

## Penggunaan

Untuk menjalankan aplikasi, gunakan perintah berikut:  
```bash  
node index.js  
```

Pastikan semua pengaturan telah dikonfigurasi dengan benar sesuai dokumentasi. Jika ada masalah, periksa log untuk mendapatkan informasi lebih lanjut.
